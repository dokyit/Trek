# Trek Feature Map

Start the isolated app before using a CLI route. Each page below describes the user path, CLI path, owning code, and visible success criteria.

## Work

- [Threads and composer](threads-and-composer.md) — start, steer, stop, and continue agent work with models, effort, plan mode, mentions, commands, skills, and attachments.
- [Thread history and inbox](thread-history-and-inbox.md) — search, pin, snooze, rename, settle, retry, rewind, fork, detach, and reopen work.
- [Projects and worktrees](projects-and-worktrees.md) — organize folders, set project defaults and actions, and isolate work in Git worktrees.
- [Basecamp and Notes](basecamp-and-notes.md) — review recent work and keep persistent Markdown notes.
- [Consulting and delegation](consulting-and-delegation.md) — ask other agents to advise, discuss, or implement as child threads.
- [Inline visualizations](inline-visualizations.md) — render safe, themed charts, heatmaps, treemaps, and UI treatment previews inside an agent answer.

## Tools

- [Git and turn changes](git-and-turn-changes.md) — inspect working-tree or per-turn diffs, commit, push, and create pull requests.
- [File Explorer and Terminal](explorer-and-terminal.md) — inspect project files and use a real shell beside the thread.
- [Editor and deep links](editor.md) — open and edit project files in-app, and reach them from `trek://` links and editor extensions.
- [Browser](browser.md) — browse, inspect elements, take page screenshots, and open devtools.
- [iOS Simulator](ios-simulator.md) — boot devices, mirror the screen, install apps, tap, type, and capture.
- [Side Chat](side-chat.md) — use a second conversation without leaving the main thread.

## Configuration and continuity

- [Agents, models, and permissions](agents-models-and-permissions.md) — configure CLI agents, API/local models, effort, hand-holding, and approval policy.
- [Skills, MCP, and computer use](skills-mcp-and-computer-use.md) — discover skills and configure agent tools and MCP servers.
- [Appearance, notifications, and snapshots](appearance-notifications-and-snapshots.md) — theme Trek, choose alerts, and attach app screenshots.
- [Phone companion](phone-companion.md) — pair an iPhone, follow threads, and answer agents remotely.
- [Imports and updates](imports-and-updates.md) — browse/resume supported local history and install signed Trek releases.
