Agents 11

  • Your CLI agents, with the logins you have
  • Any ACP agent, from the registry or your own
  • API keys and local models
  • Several accounts for one agent
  • Agents ask agents for a second opinion
  • Sub-agents, shown in their thread
  • Hand work off to a fresh thread
  • Four hand-holding levels, plus Plan mode
  • Rules that allow, ask or refuse commands
  • Your MCP servers and skills, for every agent
  • Agent CLIs kept up to date

Inbox and threads 15

  • One inbox, with what needs you on top
  • The reason in words: a question, a plan, a command
  • Answer an approval from the keyboard
  • Pin, snooze, rename and settle
  • Search everything, and a command palette
  • Undo any turn, and files roll back
  • Edit, retry or fork a turn
  • Two threads side by side
  • A side chat that leaves the thread alone
  • Your history from Claude Code, Codex and OpenCode
  • Share a thread as a link
  • Basecamp, today across every agent
  • Notes, with pictures
  • What an agent left running, with its output
  • Agents keep working with the window closed

Code and review 9

  • Each turn’s changes, to review or undo
  • Comment on lines and send them to the agent
  • Keep or undo, hunk by hunk
  • A worktree for a thread
  • Commit, push and pull requests
  • Failing checks go back to the agent
  • Live cards for pull requests and CI runs
  • An editor with language servers
  • A file explorer and a real terminal

Tools 11

  • A browser your agents can drive
  • Devtools and element picking
  • Tracker blocking and extensions Fuller on Mac
  • The iOS Simulator Mac
  • Your real iPhone, for you and your agents
  • Computer use, by element or screenshot
  • Computer use in the background Mac
  • Agents watch videos, with a transcript
  • Charts, math and live pages in answers
  • Dictation
  • Snapshots of a window or the screen

Away from your desk 5

Your agents, your providers
Prompts and code go to the agents you choose, through their own tools, as they do in a terminal. Trek never reads their logins.
Usage data only with a yes
Trek asks once. Say no and it sends nothing but feedback you choose to send. Settings shows exactly what was sent last.
Never sent
Prompts, code, file names, paths, transcripts, keys and account emails.
Phone to computer, directly
