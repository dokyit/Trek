Trek runs your coding agents from one inbox.

A native Mac and Windows app where Claude Code, Codex and your other agents work side by side, and whatever needs you comes first.

Download for macOS Source on GitHub

Free and open source. macOS 13 or later, Windows 11.

Pictured with staged threads.

Answer one, and it goes back to work.

Start as many threads as you like and leave them to it. When one stops for an approval, a question or a plan, it moves to the top of the Inbox and says why. Answer it there or from your phone. Finished work waits until you have read it.

An example with staged threads.

Your agent can run the app it just built.

On a Mac, Trek hands the agent the iOS Simulator and your iPhone. It builds the app, launches it, reads the screen and taps through its own work, while you watch in the panel beside the thread.

Pictured: Trek's own iPhone app in the Simulator, in a staged thread.

The phone is the inbox and the remote.

The agents keep running on your computer. Trek for iPhone shows every thread and what state it is in.

  • Answer approvals, questions and plans.
  • Steer a thread, or start a new one.
  • Use Notes and voice input.

Pictured with a staged thread. Built from source for now; there is no App Store build yet. How to build it

Free, and yours to read.

Trek is open source under Apache 2.0. It drives each agent's own command-line tool, so your subscriptions work as they do in the terminal.

Every release and what changed in it is on GitHub. All releases

  • macOS

    13 or later.

    Apple silicon Intel

    The first launch: the Mac build is signed but not yet notarized, so macOS stops it once. Open System Settings, then Privacy & Security, and choose Open Anyway.

  • Windows

    11, x64. Without the iOS tools.

    Installer Zip

    The first launch: the Windows build has no code signature yet, so SmartScreen asks once. Choose More info, then Run anyway.

  • iPhone

    iOS 26. Built from source for now.
