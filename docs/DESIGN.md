# Trek — Design Spec

> **v3 (2026-10-02) — references chosen by the owner:** T3 Code inbox sidebar · Capy new-thread hero ·
> MonoCode composer (model pill → Fast / Effort › / Model › with provider rail + search; access pill with
> icon + title + description rows) · Synara right panel (tab strip + launcher: Terminal, Browser, Explorer,
> Side chat, Git) · Impeccable rules for Settings (4-unit spacing, 22/14/12.5 type roles, 32px between
> sections, heading closer to its card than to the previous one, border-only cards, no eyebrows).
> Background art: procedurally dithered ridge skies (assets/backgrounds/make_backgrounds.py), user images
> supported; placement "New thread" (Capy) or "Everywhere" (window backdrop, translucent chrome).

> **v2 visual language (2026-10-02), after side-by-side review against T3 Code and Codex.**
> Neutral near-black chrome; ember is reserved for the logo and status, never for buttons or chips.
> Sidebar: search + plain "New thread ⌘N" row; live threads as quiet cards (monogram · project · status,
> then title + agent glyph); settled history folded behind "Settled (n) ——" and grouped by project (Codex).
> Content sits in an inset rounded panel. Transcript groups tool calls into one muted summary line
> ("Ran 3 commands and read 2 files ›"); only user turns get bubbles (radius 18). Composer is a radius-20 card:
> input on top, chevron chips with hairline dividers below (model · effort | hand-holding | plan), round send/stop.
> Settings swaps the sidebar for a nav column; pages are grouped cards with segmented controls.
> Where this file's older color/sidebar notes conflict with the above, the above wins.

## Brand

**Name:** Trek. **Idea:** an agent run is a trail: a sequence of switchbacks (steps) toward a summit (done).
**Line:** "Every agent. One trail."

### App icon — "Switchback"
A single continuous ribbon that zig-zags upward in perspective (wide and heavy at the base,
narrow and light near the top) and ends at a glowing **summit beacon**.
- Reads as a mountain trail, a mountain silhouette, and a stack of terminal prompts.
- The category is a wall of black/white monochrome squircles (T3, Cursor, OpenCode, Orca, Synara, Zed, Capy).
  Trek's warm sunrise gradient stands out without being loud.
- Files: `assets/brand/trek-icon-{dark,light,mono}.svg`, `trek-mark.svg` (glyph only), generated by
  `assets/brand/trek_icon.py`. `AppIcon.icns` built by `script/build-icons`.
- Variants: Dark (default), Light ("Paper"), Mono/Clear (for macOS tinted/clear icon modes).

### Menu-bar icon
18×18 pt template image (black + alpha; macOS tints it): 3-tier simplified switchback + summit dot.
States, swapped by the app:
- `idle`: ribbon + hollow dot
- `working`: ribbon + filled dot (4-frame breathing animation at 4 fps; cheap)
- `attention`: ribbon + filled dot + small notch badge (an agent needs you)
Files: `assets/brand/menubar-{idle,working,attention}.svg` → `@1x/@2x` PNG.

### Type
- UI: system (SF Pro) 13 px, line-height 1.45. Sidebar rows 13 px, meta 11.5 px muted.
- Transcript: 14 px; headings scale 1.15/1.3.

## Motion

Principles: motion explains state, never decorates. Everything interruptible (springs retarget).
Respect "Reduce motion" → crossfades only.

| Token | Use | Spec |
|---|---|---|
| `snap` | hover, press, toggles, checkbox | 90–120 ms, ease-out-quint / spring(k=700, c=45) |
| `glide` | panels, popovers, sidebar collapse, tab switch | 180–220 ms spring(k=380, c=34) |
| `settle` | inbox row arrive/leave, list reorder | 260 ms spring(k=300, c=30) + height reveal |
| `drift` | onboarding, empty states, big reveals | 420–600 ms ease-in-out, staggered 40 ms |
Exits use 70 % of the enter duration with ease-in.

### Signature moments
1. **Trail draw** (launch + onboarding): the switchback ribbon draws itself base→summit (path reveal, 700 ms),
   then the beacon ignites: scale 0→1.15→1 with a glow bloom (300 ms).
2. **Beacon status dot** (sidebar rows, menu bar): working = breathing (opacity .45↔1, 1.6 s loop);
   needs-you = two quick amber flashes then steady; done = settles into a static sky dot (unread).
3. **Thinking**: label "Thinking" with a sunrise-tinted shimmer sweep (gpui-kit `ShimmerText`), plus elapsed time.
   Collapsed reasoning expands with `MotionReveal`.
4. **Streaming text**: tokens batched per frame; new text fades from 0→1 over 120 ms (no per-glyph jitter).
5. **Inbox arrival**: row height-reveals at the top of Inbox, background flashes ember at 8 % → 0 over 600 ms.
6. **Settle** (⌘E / swipe): row slides 12 px right + fades, height collapses; it reappears under its project.
7. **Mode switch**: composer ring color crossfades 200 ms; the mode chip's icon flips (snap).
8. **Effort slider**: thumb is a spring; tick labels brighten as you pass; the beacon glow in the chip scales with effort.
9. **Tool calls**: compact one-line rows ("Edited `src/main.rs` +12 −3") that expand in place (`glide`).
10. **Update ready**: a pill slides up in the sidebar footer, "Restart to update".

### Sidebar: Inbox model (after T3 Code)
Sections, top to bottom: **Pinned · Inbox (needs you / done-unseen) · Working · Snoozed · Settled (collapsed)**,
with a project-scope filter at the top. A project-tree view is an alternative layout in Settings.
Snoozed threads wake early ("raise their hand") on approval / question / failure / completed turn.
Auto-settle after 3 days idle (configurable) or PR merge; blocked by pending approvals. Every lifecycle action
shows a 5 s Undo toast (⌘Z).

T3's schema shows how its inbox works: each thread is **unsettled** (in Inbox) or **settled** (lives under its
project), with `snoozed_until`, `pinned_at`, `pending_approval_count`, `pending_user_input_count`,
`has_actionable_proposed_plan`, `auto_settle_disabled`. Trek adopts that:
- **Inbox**: unsettled threads, sorted by *needs you* first (approvals, questions, plans), then working,
  then finished-unread. Count badge. Like Cursor's "Needs Attention" group and Codex's Activity bell.
- A thread enters Inbox when you create it, when it finishes, or when it needs input.
  It **settles** when you mark it done (⌘E), or automatically N minutes after you've read a finished thread
  (configurable; per-thread opt-out).
- **Snooze** (⌘⇧S): hide until a time; it returns to Inbox then.
- **Pinned**: manual order.
- **Projects**: grouped by repository (configurable: repo / folder / none), each showing the latest 6 settled
  threads + "Show all". Imported threads (Claude Code, Codex, OpenCode…) appear here with a source glyph.
- Row: status beacon · title (auto-generated, editable) · relative time · tiny agent glyph · diff stat `+12 −3`.
- Context menu: Pin, Rename, Mark unread, Snooze, Settle, Archive, Copy resume command, Reveal in Finder.
- Footer: Settings, update pill, account/usage ring.

### Composer
- Multiline input; `@` files/symbols/threads; `/` commands (+ skills); paste/drag images; ⌘↩ send, ↩ newline
  configurable. While running: ↩ = **steer** (inject at next step), ⌥↩ = queue (Pi/Zed/Codex pattern).
- **Model selector, Codex-style slider**: one chip opens a popover with the agent/provider list on the left and
  a **Power slider** on the right running *Faster ←→ Smarter*. Each stop is a preset (model + effort), e.g.
  for Claude: `Haiku 4.5 · Low → Sonnet 5.5 · Medium → Opus 5.5 · High → Opus 5.5 · Max`. An **Advanced**
  disclosure exposes model, effort and speed (fast mode) independently. Favorites; ⌘⇧M cycles models,
  ⌘⇧E cycles effort.
- **Hand-holding dropdown**: Supervised / Auto-accept edits / Auto / Full access, with a one-line description
  each and the ring tint. ⇧Tab toggles Plan.
- Under the composer: environment (Local / Worktree), branch picker, context meter.

### Settings (left nav, searchable)
General · Appearance · Agents & Subscriptions · API Keys · Local Models · Models & Presets ·
Permissions · Projects & Worktrees · Git & GitHub · Import Threads · Notifications & Sounds ·
Keyboard Shortcuts · Updates · Advanced · About.

## Onboarding (first run, ~60 s)
1. **Welcome**: trail-draw animation, "Every agent. One trail." [Get started]
2. **Your agents**: Trek scans PATH and ports. Rows animate in with check marks: Claude Code ✓ (signed in),
   Codex ✓, OpenCode ✓, Ollama ✓ (no models), Cursor / Copilot / Gemini → "Install" or "Sign in" buttons that
   run the vendor's own login. "Add an API key" link.
3. **Bring your threads**: found N Claude Code, M Codex, K OpenCode, T3 threads. Toggle each source; import
   indexes metadata in the background.
4. **How much hand-holding?** Four large cards (Supervised / Auto-accept edits / Auto / Full access) with
   what each will and won't do. Default: Auto-accept edits.
5. **Open a project**: Open folder… · Clone from GitHub (via `gh` auth) · recent folders found from imported threads.
6. **Done**: beacon ignites, "Start your trek."

## v4 (request 3)
- **Sidebar = T3 nightly.** Search row with three icons: *Filter by project* (popover: search, All projects,
  monogram rows with a ⚙ menu: Reveal in Finder, New thread here), *Add project* (Open folder / Clone from
  GitHub), *New thread*. Footer: ⚙ Settings · Source control · Usage · (spacer) · Updater. The updater is a
  plain icon until an update is ready, then an ember "Update" pill; its popover shows version, channel,
  progress and the one relevant action.
- **Usage popover.** Live plan limits from the vendor CLIs without sending a prompt (Claude `get_usage`,
  Codex `account/rateLimits/read`): 5-hour, weekly and per-model weekly (e.g. Fable) bars with reset
  countdowns. Refreshed when opened (30 s throttle) and every 5 min; the icon turns amber ≥80 %, red ≥95 %.
- **Composer.** Context ring (MonoCode) left of Send with "N% context used / used / window" tooltip.
  Environment chips: project · Local · branch (with a *default* tag on the default branch, changed/ahead
  counts in amber, and a branch switcher). `+` menu: photos & files, snapshot window/area/screen
  (`screencapture`), and the three pickers. Pickers: `/` commands (Trek's own first: new, usage, context,
  cost, model; then the agent's commands and skills), `@` project files + Claude sub-agents, `$` skills.
  Images can also be dropped onto the composer; they're sent as image blocks to every backend.
- **Agents & Subscriptions.** Real logos (Lobe icons), account email + plan + version, enable switch,
  Sign in / Switch account (runs the vendor's login command in a Terminal tab), Manage plan link, and an
  Install button per missing agent that runs the official install command and rescans when it exits.
- **Tools & MCP.** Computer use and Simulator toggles (served by the bundled `trek-mcp`), live
  Accessibility / Screen Recording status with deep links, AXe install, user MCP servers, and a read-only
  list of the MCP servers, skills and plugins each agent already loads.
