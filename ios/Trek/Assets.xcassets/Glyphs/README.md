# Agent glyphs

One-colour marks of the agents in `Logos`, drawn as templates so they take the tint of
the menu or label they sit in, like an SF Symbol. From Lobe Icons
(`@lobehub/icons-static-svg` 1.95.1, MIT), with each path's arc flags written out so
CoreSVG reads them; Droid's is cut from its logo in `Logos`. Same terms as `Logos`:
these marks belong to their respective owners and are shown only to identify the agent
a thread uses. No affiliation or endorsement is implied.
